# MedHELM Human Annotations

This directory contains human annotations from clinicians and medical students evaluating LLM outputs on the MedHELM benchmark.

## File: `medhelm_human_annotation.csv`

This file contains ratings from clinicians and medical students on three dimensions for LLM responses across a set of benchmarks.

### Column Descriptions

| Column | Description |
|--------|-------------|
| `username` | The annotator identifier (e.g., "Annotator 1") who performed the annotation for that row. |
| `specialty` | The medical specialty of the clinician or student performing the annotation (e.g., "Internal Medicine", "Radiation Oncology", "Medical student"). |
| `team` | The team formed during the annotation process. Each entry was annotated by multiple annotators within the same team. |
| `entry_id` | Internal identifier for the entry in the annotation UI. This ID does not map to the MedHELM leaderboard. |
| `instance_id` | The ID of the example in the MedHELM leaderboard. **Use this ID to map annotations to the leaderboard results** (e.g., when analyzing questions, responses, and their corresponding annotations). |
| `dataset_name` | The name of the benchmark to which the entry belongs (e.g., "aci_bench", "medi_qa", "mtsamples_replicate"). |
| `model_key` | The identifier of the model that generated the response (e.g., "openai_gpt-4o-2024-05-13", "anthropic_claude-3-7-sonnet-20250219"). |
| `user_label` | The label shown to annotators when viewing the response (e.g., "Model A"). These are anonymized labels, not the actual model names, to ensure unbiased annotation. |
| `question` | The prompt passed to the LLM. |
| `answer` | The response generated by the model to the prompt. |
| `accuracy` | Rating from 1 to 5 assessing the factual correctness of the response. |
| `completeness` | Rating from 1 to 5 assessing how thoroughly the response addresses the query. |
| `clarity` | Rating from 1 to 5 assessing how clearly the response is written and communicated. |

### Rating Scale

All three annotation dimensions (`accuracy`, `completeness`, `clarity`) use a 1-5 scale where higher is better.

### Linking to MedHELM Leaderboard

To map these annotations to the MedHELM leaderboard results, use the `instance_id` column along with `dataset_name` and `model_key`.
